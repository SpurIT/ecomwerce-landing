The app icon as Shopify shows it: the App Store results, the listing, the admin navigation and ad avatars.

- Upload `ecomwerce-icon-1200.png` (1200 x 1200 px, square, no rounded corners, no text) to the listing and to the app's settings in the Dev Dashboard.
- Shopify draws it at about 52 px in search results and about 20 px in the admin navigation; the platforms crop ad avatars to a circle.
- Never add text, prices or badges to it (requirements 4.2.2, 4.4.3).
