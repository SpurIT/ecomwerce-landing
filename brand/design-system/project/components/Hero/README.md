About 4.8 s, once, in css (`ew-build--intro`), so it plays without the script and ends on the finished page, which is also the html's. The page's script holds it on the icon (`ew-build--armed`) until 60% of the stage shows, shows the Before / After switch (`ew-build__switch`; Before puts the card back with `is-before`, After writes the page again with `ew-build--replay`) and drops the intro class once it ends. Transforms, opacity and clip only, so nothing shifts the layout. With reduced motion the finished page shows at once and the switch changes it without motion. `role="img"` with a text alternative for the whole story; the switch is outside it.
- Text on the drawn page stays lines, never invented copy; the product's photo, title and price are the placeholder until a real build exists (g3), then that product's.
